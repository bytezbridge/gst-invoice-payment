What is an HSN code?

HSN (Harmonized System of Nomenclature) is a 6-digit globally standardized product classification system maintained by the World Customs Organization. India extends it to 8 digits for tariff specificity. Under GST, every line item on a B2B invoice must carry an HSN code so the system knows what tax slab applies.

Example: If you sell a cell phone, its HSN is 8517 12 00 (Chapter 85 — Electrical machinery; Heading 17 — Telephones; Sub-heading 12 — Telephones for cellular networks). The GST rate attached is 12%.

Structure: 2-4-6-8 digit hierarchy

LengthWhat it identifiesExample
2-digitChapter (broad category)85 = Electrical machinery

Quick rule: The longer the code, the more specific the classification. India uses 4-digit for small businesses, 6-digit for medium, and 8-digit for tariff specificity in customs.

Method 2 — CBIC official portal

Method 3 — Cross-check with the GST rate notification

Once you have a candidate HSN, verify it against the latest "Notification No. X — Central Tax (Rate)" PDF on the CBIC site. The notifications are the legal source of truth for rates.

Common HSN mistakes

Mistake 1 — Wrong chapter

Putting "smartphone case" under chapter 85 (electronics) when it's actually 4202 (cases & containers). Always start from the product's primary material/function.

Mistake 2 — Stale rate

GST Council periodically revises rates (e.g., affordable housing went 12% → 5%, electric vehicles 12% → 5%). Using a 2-year-old rate is a common audit flag.

Mistake 3 — Ignoring price thresholds

Cotton T-shirt is 5% if priced ≤ ₹1,000 and 12% if > ₹1,000. Same HSN, different slab. Footwear and several textile items have similar threshold rules.

Mistake 4 — Mixing HSN with SAC

If you sell a "software product" (downloaded e-product), it's SAC 998434. If you sell software on a CD, it's HSN 8523. Different codes, different reconciliation paths.

Frequently asked questions

What is an HSN code?

HSN (Harmonized System of Nomenclature) is a 6-8 digit code that classifies goods worldwide for taxation. Under GST, every B2B invoice line must carry an HSN so the right tax rate applies.

Is HSN code mandatory on a GST invoice?

Yes for most. Above ₹5 crore turnover: 6-digit mandatory. ₹1.5–5 crore: 4-digit mandatory. Below ₹1.5 crore: optional (but recommended for B2B).

What is the difference between HSN and SAC?

HSN classifies goods; SAC classifies services. Both are 6-digit in India. Use HSN for products and SAC for services on invoices — never both for the same line.

How do I find the right HSN code for my product?

Use a finder tool (fastest), the CBIC HSN lookup portal (most authoritative), or cross-check the GST rate notification for the exact tariff item.

Can I use the same HSN code for similar products?

Only if they share the 6-digit classification. "Cotton T-shirt" and "cotton shirt" both fall under chapter 61 but have different headings (6109 vs 6105). Wrong HSN can shift the GST rate.

What happens if I use the wrong HSN code?

Wrong HSN means wrong rate. Issue a credit note for the wrong invoice and raise a fresh one. Repeated mistakes attract penalties and reconciliation notices.
